CAMPUS ONE — ЛИЧНАЯ СИСТЕМА СТУДЕНТА
====================================

Это локальный веб-проект без сервера, регистрации и платных зависимостей. Он запускается в обычном браузере и подходит для редактирования в Visual Studio Code.

ЧТО ВНУТРИ
----------
index.html   — структура страниц и интерфейса
styles.css   — оформление, анимации, тёмная/светлая тема и адаптивность
app.js       — логика, функции, примерные данные и локальное сохранение
README.txt   — эта инструкция

КАК ЗАПУСТИТЬ
-------------
Вариант 1 — самый простой:
1. Распакуй ZIP в отдельную папку.
2. Открой эту папку в Visual Studio Code.
3. Дважды щёлкни по index.html или нажми правой кнопкой и выбери «Открыть с помощью» браузера.

Вариант 2 — удобнее для разработки:
1. В Visual Studio Code открой Extensions (значок кубиков слева).
2. Найди расширение Live Server от Ritwick Dey и установи его.
3. Открой index.html, затем нажми Go Live в нижней панели.
4. Сайт откроется в браузере. После изменений нажимай Ctrl+S — Live Server обновит страницу.

ПОДСКАЗКА: при локальном запуске через file:// и через Live Server у браузера могут быть разные локальные хранилища. Лучше выбери один способ запуска и пользуйся им постоянно.

ВОЗМОЖНОСТИ
-----------
• Обзор учебной нагрузки: задачи, статистика и прогресс.
• Планировщик с добавлением, редактированием, удалением, дедлайнами, приоритетами и статусами.
• Недельное расписание с добавлением и редактированием занятий.
• Предметы с цветами, описаниями и собственным прогрессом.
• База знаний: заметки, поиск, фильтрация по предмету и закрепление.
• Экзамены: даты, обратный отсчёт, формат и процент готовности.
• Фокус-таймер с режимом 25, 5 и 45 минут; завершённые сессии попадают в историю.
• Карточки для запоминания, список повторения и мини-тест с объяснениями.
• Трекер привычек на неделю.
• Личный бюджет: доходы, расходы и разбивка расходов по категориям.
• Русский и таджикский интерфейс, тёмная и светлая темы.
• Экспорт/импорт резервной копии в JSON и сброс данных.
• Адаптация под телефон, планшет и компьютер.

СОХРАНЕНИЕ И ПРИВАТНОСТЬ
------------------------
Проект сохраняет данные в localStorage текущего браузера на этом устройстве. Серверу ничего не отправляется. Очистка данных браузера может удалить локальную базу, поэтому периодически открывай «Настройки → Твои данные → Экспортировать резервную копию».

Импорт резервной копии заменяет текущие данные. Перед импортом убедись, что сохранила нужную версию.

ОБРАТИ ВНИМАНИЕ
---------------
• Сведения в примере — демонстрационные, их можно отредактировать или удалить.
• Настоящая синхронизация между устройствами, вход в аккаунт, уведомления ОС и облачная база в этом офлайн-проекте не подключены.
• Внешние библиотеки и шрифты не требуются: интерфейс работает офлайн.
• Если хочется раздавать сайт другим студентам или синхронизировать между телефонами, понадобится серверная часть и база данных.

УПРАВЛЕНИЕ
----------
Кликни по разделу слева. Кнопки «+» открывают форму. В расписании клик по свободному слоту добавляет занятие, а по занятому — открывает редактирование. В «Учебной лаборатории» нажимай на карточку, чтобы перевернуть её. Фокус-сессия засчитывается в статистику после завершения таймера.
